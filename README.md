# Xaden Quintero-Watson — GitHub Portfolio

A responsive, single-page portfolio designed for GitHub Pages.

## Files
- `index.html` — main portfolio
- `style.css` — responsive styling
- `script.js` — small navigation enhancement
- `resume.pdf` — resume linked from the site

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `portfolio`).
2. Upload all files in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide your Pages URL.

## Notes
The Aztec Appraisals project uses the public Power BI report URL supplied for the portfolio. If Power BI blocks embedding in an iframe, the “Open full Power BI report” link still works.
